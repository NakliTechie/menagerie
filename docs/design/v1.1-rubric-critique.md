## Grid — mixed tiles (desktop)

PASS. PTY terminal tile and structured stream tiles render simultaneously in one
grid; status dots are identical vocabulary across both kinds. The omp tile shows
the full instrument pattern: thinking row, one-line tool rows with ✓ marks,
clamped agent message with fade-out tail, and the accent **permission strip**
("▮ permission requested — Edit main.py · review →") — pending state without
leaking the diff at tile scale, exactly per §7.

Findings:
- MINOR: structured tile bodies leave empty space below short content — within
  instrument density, no action.
- MINOR (pre-existing v1.0): footer pills float over the bottom-right tile's
  input bar at this viewport; unchanged by this milestone.

## Drill-in + diff review

PASS. Breadcrumb head with ← back and `{}` raw-log toggle; instrument bar;
session rail with live dots; transcript (thought collapsible, tools with status
marks, agent message); diff card with **path visible** (`main.py`), ⚑ pending
state, hunk header (`@@ -3 +3 @@`), red del / green add washes, per-hunk ✓/✕
buttons, explicit Approve / Reject buttons; permission banner above a multiline
composer.

Findings:
- MINOR: with sparse transcripts the middle region is mostly empty — acceptable;
  density comes from real content, not filler.
