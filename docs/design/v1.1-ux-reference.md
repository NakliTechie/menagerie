# Menagerie v1.1 — UX/UI Reference

> **Gate document (handoff §7).** C3 and C4 do not open until this exists. It fixes
> every new surface, its states, and the tokens they use — before any browser code
> is written. Edit here first if the design moves during the build.

## Unity sentence

> **An instrument panel for work in progress — dense, legible at a glance, never
> hiding what the agent actually did.**

Not a chat app: no avatars, no bubbles, no typing indicators, no empty-state mascot.
Density over decoration. The terminal tile was the v1.0 instrument; the message
stream is the v1.2 one. Same chrome, different glass.

## Tokens

Everything reuses the existing Rangrez ramp. No new type family, no second accent,
no new color variables. Mapping for new surfaces:

| Meaning | Token |
|---|---|
| Stream background / panels | `--panel`, `--panel-2`, `--bg` |
| Text hierarchy | `--text` · `--muted` · `--faint` |
| Borders, radius, fonts | `--border`, `--radius(-sm)`, `--sans` for prose, `--mono` for code/diffs/logs |
| Agent text | `--text` |
| Thinking (collapsed) | `--faint`, dimmed block |
| Tool call rows | one line, `--muted`; expand to full detail |
| Diff add | `--green` (+ 12% alpha wash) |
| Diff del | `--red` (+ 12% alpha wash) |
| Permission pending | existing `s-needs_input` red pill language |
| Backpressure drop marker | `--yellow` inline strip |

## 1. Structured tile at grid density (C3)

Same `.tile` head (dot · title · timer · actions) and `.tile-input` bar as PTY
tiles. Only `.tile-term` swaps for `.tile-stream`. **Tile shows the last message
and the current activity — not the transcript.**

```
┌──────────────────────────────────────────────────┐
│ ● omp · localhost · 04:12              ⛶  ⤢  🗂 │   ← dot = status pill (unchanged)
├──────────────────────────────────────────────────┤
│  ▸ Bash · ls -la src/                     ✓ 0.8s │   ← last tool call: ONE line,
│  ▸ Read · src/main.go                     ✓      │     collapsed, dim, occupies row
├──────────────────────────────────────────────────┤
│                                                  │
│  Rewrote the parser to accept UTF-8 identifiers  │   ← last agent message (clamped
│  and added tests for the failing case.           │     ~5 lines, fade-out tail)
│                                                  │
│  ░░░░░░░░░░░░░░ older activity on drill-in ░░░░░ │
├──────────────────────────────────────────────────┤
│ [ reply / prompt…                         ] [↵] │   ← prompt goes via `prompt`,
└──────────────────────────────────────────────────┘     not `input`
```

Permission pending at tile scale — *that one is pending*, never the diff:

```
├──────────────────────────────────────────────────┤
│ ▮ permission requested — Edit main.py  [review →]│   ← accent strip, click = drill-in
├──────────────────────────────────────────────────┤
```

Thinking renders as a dim collapsible row (`▸ thought · 214 tokens`). Tool calls
are one-line rows: kind glyph, short label, status tick. **Dim, never hide** — a
collapsed call still owns its row.

## 2. Drill-in surface (C4)

An **in-page surface that replaces the grid and returns to it**, preserving scroll
position and tile order (grid stays in DOM, hidden — not rebuilt, not a modal, not
a new tab).

```
┌ topbar ──────────────────────────────────────────────────────────┐
┌─────┬────────────────────────────────────────────┬───────────────┐
│ rail│  INSTRUMENT BAR                            │               │
│ ·omp│  ctx ▮▮▮▮▮▯▯▯ 62% · model opus · think med │  (right rail  │
│ ●mini│───────────────────────────────────────────│   folds into  │
│     │  TRANSCRIPT                                │   instrument  │
│     │  ❯ user: fix the failing test              │   bar ≤900px) │
│     │  ▸ thought · 214 tok                [▾]    │               │
│     │  ▸ Bash · pytest -x                 ✓      │               │
│     │    └ $ pytest -x test_review.py            │               │
│     │  ✎ Edit · src/review.py             ⚑ 1 hunk│              │
│     │  agent: Fixed the off-by-one…              │               │
│     │───────────────────────────────────────────│               │
│     │  DIFF REVIEW (pending)                     │               │
│     │  src/review.py                  [✓][✕] all │               │
│     │  ┌ hunk 1 ────────────────── [approve][rej]│               │
│     │  │ -def run():                             │               │
│     │  │ +def run(verbose=True):                │               │
│     │  └────────────────────────────────────────│               │
│     │───────────────────────────────────────────│               │
│     │  COMPOSER (pending permission shown here) │               │
│     │  ┌───────────────────────────────┐ [send] │               │
│     │  │ multiline…                    │        │               │
└─────┴────────────────────────────────────────────┴───────────────┘
```

Regions: **transcript** (full stream; thinking toggleable) · **diff review** ·
**session rail** (switch without routing through the grid) · **instrument bar**
(context gauge, model, thinking level, token counters *when the agent exposes
them* — absent data collapses, never fabricates) · **composer** (multiline,
shows pending-permission state).

### Diff review — three states

```
PENDING          │ APPROVED           │ REJECTED
⚑ 1 hunk pending │ ✓ applied          │ ✕ rejected — agent informed
[approve] [reject]│ (row dims to done) │ (explicit rejection SENT;
                  │                    │  never silence)
per-hunk: [✓][✕] on each hunk header · [approve all] on file header
Where ACP gives a structured diff → render hunks. Where it gives only a shell
command tool call → render THE COMMAND; do not fabricate a diff.
```

Syntax highlighting: CDN-pinned highlighter allowed per hard-NOT #3 rules
(probe → degrade to plain text). v1.2 ships plain-text diff rendering with
add/del washes; a highlighter may land later through the probe-degrade path.

### Escape hatch — raw event log

One keystroke (`d`) or the `{} ` button toggles the raw event-log pane:
monospace JSONL of exactly what crossed the wire, newest at bottom. When the
render layer doesn't understand a frame, the person still can.

## 3. Grid ↔ drill-in transition (the design work)

- **In:** click a structured tile's body/head (or `Enter` on focused tile). Grid
  hides (`display:none` — DOM untouched), drill surface slides in with a single
  160ms fade+rise. Tile order, drag order, scroll positions all survive because
  nothing is destroyed.
- **Out:** `Esc` or the ← breadcrumb. **Esc returns to the grid ONLY when the
  composer has no pending text** — losing a half-written prompt is the bug that
  gets reported first. With text pending, first Esc flashes the composer border
  (accent) instead.
- PTY tiles never drill; `Enter`/`f` keeps their fullscreen behavior.

## 4. Empty & error states

| State | Tile/stream shows |
|---|---|
| Spawned, silent | `waiting for the agent's first frame…` (muted, pulsing dot) |
| ACP handshake failed | error pill + `agent failed to start (acp handshake) — see raw log` |
| Frames dropped (backpressure) | inline `--yellow--` strip: `⚠ N frames dropped (slow connection)` |
| Relay lost mid-session | existing `lost` grey-red tile treatment, unchanged |
| Unknown ACP update kind | raw frame rendered dim inside the stream (never swallowed) |

## 5. Keyboard additions (checked against v1.0 table)

| Key | Context | Action |
|---|---|---|
| `Enter` | focused structured tile | drill in |
| `Esc` | drill-in, empty composer | return to grid |
| `Esc` | drill-in, composer has text | flash composer, stay |
| `d` | drill-in | toggle raw event-log pane |
| `Tab` | unchanged | cycle tiles |

Added to the v1.0 hotkey table in the same commit as the implementation.
