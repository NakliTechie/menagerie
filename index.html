Menagerie.

A browser-native console for running and watching fleets of coding agents — Claude Code, Codex, opencode, Aider and friends — side by side in one window.

How it works. This page is the whole app. It talks over WebSocket to small relays you run next to your agents (your laptop, a server, wherever). Each relay streams its agents' terminals here. No NakliTechie server, no account, no telemetry — nothing leaves your machines.
Get going

1 · Run a relay. One small server you run once per machine — not per agent; it launches and streams every agent on that box, so leave it running. Install it with Homebrew (macOS / Linux):

brew install naklitechie/tap/menagerie-relay
menagerie-relay init
menagerie-relay serve

No Homebrew? Download the binary (then chmod +x and run it as ./menagerie-relay), or build with go install …/menagerie-relay@latest. macOS browser-downloads only: xattr -dr com.apple.quarantine menagerie-relay.

2 · Connect it. Open Settings (⚙) — the localhost relay is listed there with a step-by-step that detects it and walks you through pasting the token.

3 · Spawn. Hit + Spawn, pick an agent, and go. ◐ switches light / dark.
